# Kamélia - Landing Page de Cosméticos Naturais 🌸

Este projeto é uma Landing Page responsiva, acessível e elegante desenvolvida para a marca de cosméticos artesanais **Kamélia**. O site foi construído do zero como parte do cumprimento do **Desafio 01**, focando na aplicação prática de estruturas web semânticas e estilização moderna.

## 🚀 Tecnologias Utilizadas

- **HTML5** (Estruturação Semântica)
- **CSS3** (Layout responsivo com Flexbox e Grid)
- **Git & GitHub** (Controle de versão e hospedagem)

## 📦 Funcionalidades e Requisitos Atendidos

- **HTML Semântico:** Uso correto e consciente das tags `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` e `<footer>`.
- **Acessibilidade:** Imagens configuradas com atributos `alt` descritivos e respeito à hierarquia de títulos (`<h1>` a `<h3>`).
- **Responsividade:** Layout totalmente adaptável para dispositivos móveis (smartphones e tablets) e desktops, utilizando unidades flexíveis e media queries sem barras de rolagem horizontal indesejadas.
- **Formulário de Contato:** Seção dedicada para captação de mensagens de clientes com validação nativa.

## 🤖 Documentação do Uso Consciente de IA

Em conformidade com as diretrizes do desafio, inteligências artificiais (Google Gemini e Claude AI) foram utilizadas como copilotos estratégicos durante o desenvolvimento. O objetivo foi entender a aplicação das propriedades e não apenas copiar códigos.
